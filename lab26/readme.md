# Предварительная обработка звука

Для машинного обучения есть разные способы хранить звук и его обрабатывать, в зависимости от задачи предсказания.

1. Установите новые пакеты
2. Запустите примеры из файла `lab26_pre` для трех примеров звуковых дорожек.
3. Загрузите свои дорожки и на их примере посмотрите различные представления, для каких целей каждое представление лучше подойдет?
4. Для совместно выбранной задачи возьмите 2 способа предобработки и обработайте данные из задачи.
5. Выберите архитектуру и обучите модель для решения задачи. Сравните результаты обучения для 2х разных способов предобработки
