## Задание для самостоятельного выполнения

**Дано:** датасет `ml-100k` (встроенный в Surprise).

**Задачи:**

1. Загрузите датасет и разделите его на обучающую (75%) и тестовую (25%) выборки.
2. Создайте две модели kNN:
   - user‑based (поиск похожих пользователей) с k = 30, мера сходства — косинусная.
   - item‑based (поиск похожих объектов) с k = 30, мера сходства — косинусная.
3. Обучите обе модели и вычислите для каждой RMSE и MAE.
4. Сравните полученные метрики. Какая модификация (user‑based или item‑based) дала меньшую ошибку на данном наборе данных?
5. (Дополнительно) Для одного выбранного пользователя предскажите оценку для трёх фильмов, которые он не оценивал. Выведите предсказания в удобном виде.

Для использования в Surprise достаточно указать название меры в параметре `'name'`.
